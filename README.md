# 🌐 Chronioñ Browser

**Chronioñ Browser** es un navegador web nativo para Android creado con Jetpack Compose y Kotlin, diseñado para ofrecer una navegación rápida, privada y personalizable.

---

## 🚀 Características Principales

* **🛡️ Ad-Block Nativo:** Bloqueo de anuncios e integración de protecciones de privacidad.
* **🌙 Modo Oscuro y Cuidado Visual:** Soporte para Dark Mode y filtro de luz azul integrado.
* **📂 Gestor de Descargas y Extensiones:** Interfaz dedicada para administrar archivos y extensiones/UserScripts.
* **📖 Modo Lectura:** Limpia el contenido para facilitar la lectura sin distracciones.
* **🛠️ DevTools e Inspector:** Herramientas integradas para inspección y desarrollo web.
* **🌐 Traducción Automática:** Barra de traducción integrada para páginas en otros idiomas.
* **🔍 Búsqueda Avanzada:** Filtros instantáneos por categoría (Noticias, Imágenes, Videos, Código, etc.).
