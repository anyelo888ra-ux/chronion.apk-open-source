# 🌐 Chronioñ Browser

**Chronioñ Browser** es un navegador web nativo para Android creado con Jetpack Compose y Kotlin, diseñado para ofrecer una navegación rápida, privada y personalizable.

---

## 🚀 Características Principales

* **🛡️ Ad-Block Nativo:** Bloqueo de anuncios e integración de protecciones de privacidad.
* **🌙 Modo Oscuro y Cuidado Visual:** Soporte para Dark Mode y filtro de luz azul integrado.
* **📂 Gestor de Descargas y Extensiones:** Interfaz dedicada para administrar archivos y extensiones/UserScripts.
* **📖 Modo Lectura:** Limpia el contenido para facilitar la lectura sin distracciones.
* **🛠️ DevTools e Inspector:** Herramientas integradas para inspección y desarrollo web.
* **🌐 Traducción Automática:** Barra de traducción integrada para páginas en otros idiomas.
* **🔍 Búsqueda Avanzada:** Filtros instantáneos por categoría (Noticias, Imágenes, Videos, Código, etc.).

## 🛠️ Requisitos e Instalación

1. **Clona este repositorio:**
   ```bash
   git clone https://github.com/anyelo888ra-ux/chronion.apk-open-source.git
   cd chronion.apk-open-source
   ```

2. **Compilación:**
   * Abre la carpeta del proyecto en **Android Studio**.
   * Sincroniza los archivos de Gradle.
   * Compila el proyecto desde el menú superior: `Build > Build Bundle(s) / APK(s) > Build APK(s)`.

---

## 🌐 Página Web Oficial (Landing Page)

El proyecto incluye una interfaz web moderna alojada en GitHub Pages para gestionar las descargas de forma pública y segura. 

El archivo `index.html` base del sitio web cuenta con un sistema de diseño oscuro profesional, distribución responsiva mediante Flexbox/Grid y una pasarela de protección automatizada con la API de **Google reCAPTCHA** para mitigar descargas de bots y asegurar la integridad del servidor.
